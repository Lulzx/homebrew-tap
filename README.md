# Lulzx Tap

## How do I install these formulae?

`brew install lulzx/tap/<formula>`

Or `brew tap lulzx/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "lulzx/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
